0.2 是离线单机的全球征服版本：在真实地球地貌与海岸线上经营城市、发展科技、调动军团。国家采用真实名称，开局部署及八方混战为架空设定，不是历史战局复原。部队沿 **68 个战略地区之间的路线** 行动；这是一套全球战略路线地图。

## 本版内容

- **8 个可选势力**：英国、德国、苏联、美国、中国、日本、法国、意大利，各有开局科技与兵种加成；其他七方由 AI 逐一行动。
- **6 条科技线，各 3 级**：陆军火力、防护装甲、战地补给、工业动员、航空工程、海军工程。科技实际改变火力、防御、机动、收入与兵种解锁。
- **8 种势力专属兵种**：皇家突击队、虎式重装甲、近卫坦克军、谢尔曼突击群、山地精锐师、零式航空队、外籍精锐军团、快速机动军。陆军火力 II 解锁本国精锐；航空精锐还需要航空科技。
- 普通步兵、装甲、火炮、战机、驱逐舰；城市招募、兵力修复、部队晋级、城市收入和科研。
- **内置单机修改器**：资源辅助、我方无敌、无限行动、即时科研。开关可分别控制，效果和状态随战役存档保存。
- 地图拖动、缩放、区域观察和战场详情界面；实际地貌贴图、单位贴图、国家标识。**无音效**。

## 安装与玩法

将 `IronMeridian-0.2.0.apk` 下载到手机，点击安装，并按手机提示允许该来源安装应用。支持 **Android 7.0 / API 24 以上、OpenGL ES 3.0、ARMv7 与 ARM64**；横屏，完全离线。此包使用开发测试签名，未上架应用商店；本版 APK 不包含 x86 架构。

1. 选择国家及难度，进入全球征服。
2. 选中部队后，点击可达地区移动，或点击射程内敌军攻击。每个地区只容纳一支部队；进入无守军地区即可占领。
3. 在己方地区招募、补给或升级部队，在科技面板投入军费和科研。海运路线为陆军提供自动运输，舰艇只能部署和行动于沿海地区。
4. 结束回合后，存活的其他势力依次行动。**80 回合内占领全部 8 座首都获胜；己方首都失守或超时失败**。势力失去首都后，部队解散，剩余领土转为中立。
5. 修改器位于游戏内面板，可在单机战役中开启。开启后仍需选中部队、地区或科技执行对应操作。

航空和海军采用地区层级的简化规则，航空单位也能进入地区并占领；路线代表战略通道，不精确模拟道路和每段海岸线。当前版本不含外交同盟、联机和完整历史剧本。

自动存档使用新的 **v2 战役存档槽**。旧版 0.1 的存档保留在独立文件中，不会转换成全球战役。

## 开发与验证

使用 **Godot 4.6.3** 打开 `project.godot`。直接使用当前 checkout；云任务已有隔离环境，无需新建 worktree。

```bash
godot --path .
bash scripts/test.sh
bash scripts/build_android.sh
```

测试脚本为本次运行创建独立的 `/tmp` 用户目录，执行世界规则测试、游戏界面流程测试，以及存在时的地图输入回归测试，不读取或覆盖正常游戏存档。新增规则测试涵盖八方行动、科技收益与解锁、专属兵限制、修改器、占领和存档恢复。

Android 构建需要 Godot 同版本导出模板、JDK 17+、Android SDK platform-tools 与 build-tools 35.0.1+。当前云环境的工具链位于 `/workspace/toolchains`，构建脚本会自动选择该目录。其他机器需先在 Godot 编辑器设置中指定 Java SDK / Android SDK。输出默认为 `artifacts/IronMeridian-0.2.0.apk`，采用非 Gradle 导出；本地测试签名密钥不应提交到仓库。

**设备验证限制**：此前云端安卓模拟器发生 `DeadSystemException`，应用管理服务失效。不能据此宣称本版已完成安卓内运行或真机兼容性验证；构建、签名检查和桌面自动化测试与真机验证是不同检查。

## 主要文件与素材

- `game/world_battle.gd`：势力、科技、兵种、战斗、AI、修改器和 v2 存档规则。
- `game/world_main.gd`：国家选择、战场面板、科技、招募、修改器与自动存档界面。

- `assets/world/world.json`：68 个战略地区、100 条路线，其中 29 条海运路线。
- `scripts/generate_world.py`：地理数据与地图的可重复生成脚本。
- `tests/test_world.gd`：世界征服规则回归测试。
- `assets/world/ATTRIBUTION.txt`：Natural Earth 国界、地球地貌贴图的来源与授权；字体及引擎授权见 `assets/licenses/`。
