# Original military sprite art

`units.png` and `elites.png` are original AI-generated miniature unit artwork created for this project with OpenAI image generation. No source artwork or textures from World Conqueror were used.

Both files are 1774×887 RGBA transparent PNGs, arranged in four columns and two rows (each atlas cell is 443.5×443.5 pixels). Godot `draw_texture_rect_region` accepts fractional source regions; see `atlas.json` for exact mappings.

- units row 1: infantry, medium tank, artillery, fighter.
- units row 2: destroyer, heavy tank, alternate commando squad, rocket artillery.
- elites row 1: British commandos, German Tiger-style tank, Soviet guards, US Sherman-style tank.
- elites row 2: Chinese volunteers, Japanese Zero-style aircraft, French legion, Italian bersaglieri.

The silhouettes were generated in a consistent original miniature style. Historical equipment names identify visual archetypes; no official game branding or copied game assets are included.
